## 1. എന്താണ് ഈ സിസ്റ്റം? (What is this system?)

നിങ്ങളുടെ **MysteryVerse Malayalam** യൂട്യൂബ് ചാനലിനായി പൂർണ്ണമായും ഓട്ടോമാറ്റിക് ആയി:
1. പുതിയ അറിവുകളും വിഷയങ്ങളും കണ്ടെത്തുന്നു (Science, Space, History, Mysteries, General Knowledge).
2. ആകർഷകമായ മലയാളം കഥകളും സ്ക്രിപ്റ്റുകളും തയ്യാറാക്കുന്നു.
3. നിങ്ങളുടെ സ്വന്തം ആനിമേറ്റഡ് കഥാപാത്രമായ **jobelessboy**-നെ ഉപയോഗിച്ച് ചുണ്ടനക്കവും (Lip-sync), കണ്ണടച്ചു തുറക്കലും (Eye-blink), ശരീര ചലനങ്ങളും നൽകി വീഡിയോകൾ നിർമ്മിക്കുന്നു.
4. വീഡിയോയുടെ താഴെ വ്യക്തമായ **English Subtitles** നൽകുന്നു.
5. യൂട്യൂബ് Shorts (9:16) വീഡിയോകളും Long (16:9) വീഡിയോകളും നിർമ്മിച്ച് തരുന്നു.

## 2. സിസ്റ്റം എങ്ങനെ സ്റ്റാർട്ട് ചെയ്യാം? (How to start the system?)

സിസ്റ്റം ഉപയോഗിക്കാൻ വളരെ എളുപ്പമാണ്:

### പടി 1: ബാക്കെൻഡ് സ്റ്റാർട്ട് ചെയ്യുക (Backend)
ഒരു ടെർമിനൽ തുറന്ന് താഴെ കാണുന്ന കമാൻഡ് നൽകുക:
```powershell
cd c:\m\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```
*(ഇത് നിങ്ങളുടെ AI എഞ്ചിനും ഷെഡ്യൂളറും ഓൺ ആക്കുന്നു)*

### പടി 2: ഡാഷ്‌ബോർഡ് തുറക്കുക (Dashboard)
രണ്ടാമതൊരു ടെർമിനൽ തുറന്ന് താഴെ കാണുന്ന കമാൻഡ് നൽകുക:
```powershell
cd c:\m\frontend
cmd.exe /c npm run dev -- --host 127.0.0.1 --port 5173
```
ഇനി നിങ്ങളുടെ ബ്രൗസറിൽ ഈ ലിങ്ക് തുറക്കുക:  
👉 **`http://127.0.0.1:5173`**

നിങ്ങൾക്ക് മുന്നിൽ മനോഹരമായ ഒരു കൺട്രോൾ പാനൽ (Dashboard) തുറന്നുവരും!

## 4. പ്രധാന നിയമം: സ്ക്രീനിൽ ഇംഗ്ലീഷ് മാത്രം (Screen Rule: English Only)

നമ്മുടെ ചാനലിന്റെ ഏറ്റവും പ്രധാനപ്പെട്ട നിയമം ഇതാണ്:
* **സംസാരം (Narration):** പൂർണ്ണമായും സ്വാഭാവികമായ മലയാളത്തിൽ ആയിരിക്കും.
* **സ്ക്രീനിലെ എഴുത്ത് (On-Screen Text):** സ്ക്രീനിൽ **മലയാളം അക്ഷരങ്ങൾ ഒരിടത്തും വരില്ല**. 
* **സബ്ടൈറ്റിലുകൾ:** മലയാളത്തിൽ പറയുന്ന കാര്യങ്ങൾ കൃത്യമായ **English Subtitles** ആയി സ്ക്രീനിന്റെ താഴെ തെളിഞ്ഞു കാണും.
* **ചാനലിന്റെ പേര്:** സ്ക്രീനിൽ കാണിക്കുന്നത് **`MYSTERYVERSE MALAYALAM`** എന്ന് ഇംഗ്ലീഷിൽ മാത്രമായിരിക്കും.

ഇത് ലോകമെമ്പാടുമുള്ള ആളുകൾക്ക് വീഡിയോ കാണാനും വീഡിയോയ്ക്ക് അന്താരാഷ്ട്ര നിലവാരം (International Standard) നൽകാനും സഹായിക്കുന്നു.
